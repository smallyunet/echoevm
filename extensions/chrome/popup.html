Local transaction execution

EchoEVM Replay

Wasm engine included

No local CLI installation is required.

  1. Open an Ethereum Mainnet transaction on Etherscan.
  2. Open the EchoEVM panel in the lower-right corner.
  3. Select a self-contained replay witness; execution starts locally.

Etherscan does not expose complete historical prestate on the page. EchoEVM therefore requires a versioned witness instead of silently depending on a remote executor.
