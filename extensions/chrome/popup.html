No local CLI installation is required.

  1. Open a verified contract on Etherscan to inspect its ABI and bytecode.
  2. Run ABI functions marked pure in the local empty-state sandbox.
  3. Or open a transaction and import a self-contained witness for exact replay.

Contract Lens never presents an empty-state sandbox as Mainnet simulation. Stateful execution still requires explicit historical prestate.
