# EchoEVM Skill A/B Pilot Results — 2026-08-03

## Verdict

The strict pilot completed 24 independent Codex runs: four Solidity tasks,
two conditions, and three repetitions. Both conditions passed all hidden tests.

EchoEVM did not improve the aggregate pass rate and did not reduce aggregate
cost on this easy-to-medium task set. Its benefit was task-dependent:

- CREATE2 prediction: faster and lower-token with the skill.
- Packed calldata decoding: faster with a small non-cached-token increase.
- Simple fee arithmetic: effectively neutral non-cached-token cost and slightly
  slower.
- Obvious loop-to-formula gas optimization: substantially slower and more
  expensive because the agent explored a deployment-gas versus call-gas
  mismatch repeatedly.

The strongest demonstrated value is deterministic execution and embedded-Geth
evidence for EVM-sensitive work, not universal token reduction.

## Fixed environment

- EchoEVM: v0.0.37, commit `bee203b`
- Solidity: 0.8.33
- Forge: 1.3.6-nightly
- Codex CLI: 0.146.0-alpha.9.2
- Model: gpt-5.6-sol, medium reasoning
- Conditions: control versus `echoevm-debug`
- Runs: 4 tasks x 2 conditions x 3 repetitions = 24
- Ordering: seeded random order, two concurrent workers
- Grading: hidden Foundry tests injected after the Codex session

Every run used explicit `./.benchmark-bin/...` paths. All 12 treatment runs
read `echoevm-debug`, verified the pinned EchoEVM version, and produced
EchoEVM execution evidence. Control runs received an unavailable EchoEVM
placeholder and produced no EchoEVM evidence.

`input + output` includes cached input. The non-cached measure is

## Sum-to failure mode

The task required a function call below 20,000 gas. Agents first used:

```text
echoevm solidity run ... --gas 20000
```

That path also needs enough gas to deploy the contract, so it failed before the
intended runtime-call measurement. Skill runs retried several inputs, raised the
gas limit for deployment, extracted runtime bytecode, encoded calldata, and
finally used `echoevm diff --gas 20000` to verify the call correctly.

The final answer was correct, but the route caused most of the aggregate
overhead. The skill should explicitly route low call-gas thresholds to runtime
bytecode plus calldata, or EchoEVM should expose separate deployment and call
gas limits.

## Limitations

- The task set was small and all fixes were solvable by source inspection.
- Three repetitions per cell are enough for a pilot, not a broad performance
  claim.
- Evidence completeness was audited structurally, not scored by blind human
  reviewers.
- The benchmark measures one model, one Codex version, and one machine.
